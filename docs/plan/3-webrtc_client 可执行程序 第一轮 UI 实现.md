# webrtc_client 可执行程序：第一轮 UI 实现

## 交付目标

交付能够独立启动的 `webrtc_client` 桌面程序，使用 Qt 6 + QML，包含上方九宫格视频区域和下方工具栏。本轮不接入 WebRTC，不开发 `webrtc_engine`。

交付内容包括：

- 当前 macOS 环境可直接启动的 `webrtc_client.app`，包含运行所需的 Qt 库和 QML 资源，无需用户另行安装 Qt。
- 完整源码，以及 Windows、macOS、Linux 的构建与部署说明。
- 开发记录，明确产物位置、启动方式、实际验证结果和未完成事项。

三平台均为目标平台；Windows 的 `webrtc_client.exe` 和 Linux 的 `webrtc_client` 必须分别在对应环境构建验证。未具备对应环境时明确记录为待交付，不以源码或 macOS 产物代替。

## 界面与交互

- 使用深色专业风格、系统标题栏；默认窗口 `1440×900`，最小 `960×640`。
- 上方固定三行三列，九个等大视频卡片随窗口缩放，显示通道编号、“暂无视频”和“未连接”，预留保持 16:9 比例的视频区域。
- 下方工具栏包含七个按钮：开启麦克风、开启摄像头、开启扬声器、预览摄像头、开始推流、开始拉流、设置。
- 按设备、预览、流控制和配置分组，设置靠右；按钮包含图标、中文文字、悬停提示和键盘焦点反馈。
- 本轮点击按钮只显示功能尚未接入的提示，不访问设备、不连接网络、不显示虚假的运行状态。
- 后续接入 engine 时，原按钮可切换为关闭、停止或静音操作，本轮不实现这些业务行为。

## 工程与部署

- 使用 CMake、C++17、Qt 6.5 及以上版本，依赖 Qt Quick 和 Qt Quick Controls，可执行目标命名为 `webrtc_client`。
- `webrtc_client_ui/` 独立承载启动入口、QML 组件、主题和图标资源；本轮不创建 engine 实现或业务接口。
- 当前环境尚未发现可用的 Qt/CMake 工具链，实施时先准备构建环境，再编译并生成可运行产物。
- 使用 Qt 部署工具收集运行依赖；macOS 产物放入项目的 `dist/` 目录，提供准确路径和启动说明。
- 本轮交付本地运行版本，暂不包含发行签名、公证和安装器。
