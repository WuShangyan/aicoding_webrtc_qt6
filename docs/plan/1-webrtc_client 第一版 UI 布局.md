# webrtc_client 第一版 UI 布局

## 目标与范围

创建可运行的 Qt 6 桌面程序 `webrtc_client`，面向 Windows、macOS、Linux，使用 QML 实现深色专业风格界面：上方固定九宫格视频区域，下方功能工具栏。

本次仅实现布局和按钮占位提示，不访问音视频设备，不接入 WebRTC，不开发 `webrtc_engine`。

## 工程与分层

- 使用 CMake、C++17、Qt 6.5 及以上版本，依赖 Qt Quick 和 Qt Quick Controls。
- 根工程管理构建，`webrtc_client_ui/` 承载启动入口、QML 模块和界面资源，生成名为 `webrtc_client` 的可执行程序。
- C++ 仅负责应用启动与 QML 加载；QML 拆分为主窗口、视频网格、视频卡片、底部工具栏和统一主题。
- 文档说明未来由 UI 调用 `webrtc_engine` 接口；本次不创建 engine 实现、模拟引擎或尚未确定的业务接口。

## 界面与交互

- 窗口标题为 `webrtc_client`，默认大小 `1440×900`，最小大小 `960×640`，使用系统标题栏。
- 视频区域占据工具栏之外的剩余空间，始终保持三行三列；九个卡片等大，窗口缩放时同步调整。
- 卡片使用深色底、细边框和圆角，显示“视频通道 01–09”“暂无视频”和“未连接”状态。预留居中的 16:9 视频显示区域，尺寸不足时留黑边，不裁切内容。
- 底部工具栏固定高度，依次展示“启动音视频设备”“预览摄像头”“开始推流”“开始拉流”“设置”，采用图标加中文文字，并提供悬停与键盘焦点反馈。
- 所有按钮点击后显示可自动消失的提示：“〈功能名称〉尚未接入，当前仅展示 UI”。不改变连接、设备或播放状态。
- 界面使用深灰背景、略浅的视频卡片及蓝色操作强调；图标采用随应用打包的资源，不依赖在线资源或平台字体图标。
- 不增加设置表单、地址输入、布局切换、全屏或模拟视频。
