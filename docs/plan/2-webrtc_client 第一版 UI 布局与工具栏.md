# webrtc_client 第一版 UI 布局与工具栏

## 目标与范围

创建使用 Qt 6 + QML 的 `webrtc_client`，面向 Windows、macOS、Linux，采用深色专业风格，上方展示九宫格视频，下方提供按用途分组的工具栏。

本次实现界面布局、按钮反馈和占位提示，不访问设备、不执行推拉流、不开发 `webrtc_engine`。

## 工具栏设计

将原来的“启动音视频设备”拆分为独立控制，方便后续分别操作麦克风、摄像头和播放声音。

| 分组 | 控件 | 后续接入功能时的用途 |
|---|---|---|
| 音视频设备 | 麦克风 | 开启或关闭音频采集 |
| 音视频设备 | 摄像头 | 开启或关闭视频采集 |
| 音视频设备 | 扬声器 | 开启或静音接收流的声音 |
| 本地预览 | 预览摄像头 | 显示或关闭本地画面 |
| 流控制 | 开始推流 | 开始后切换为“停止推流” |
| 流控制 | 开始拉流 | 开始后切换为“停止拉流” |
| 配置 | 设置 | 后续配置设备、推拉流地址和音视频参数 |

- 设备组、预览组、流控制组、配置组之间使用间距和细分隔线区分，设置按钮靠右。
- 按钮采用图标加中文文字，提供悬停提示、按下和键盘焦点反馈。
- 麦克风、摄像头、扬声器的初始文字分别为“开启麦克风”“开启摄像头”“开启扬声器”；预览初始文字为“预览摄像头”。
- 本次点击任一按钮仅显示“〈功能名称〉尚未接入，当前仅展示 UI”，不切换设备或连接状态，不展示虚假的音量和运行数据。
- 暂不增加独立的停止按钮；未来推流、拉流和预览通过原按钮切换开始与停止状态。
- 工具栏采用紧凑布局，在最小窗口尺寸下仍完整显示全部七个按钮。

## 布局与工程分层

- 使用 CMake、C++17、Qt 6.5 及以上版本，依赖 Qt Quick 和 Qt Quick Controls；可执行程序名为 `webrtc_client`。
- `webrtc_client_ui/` 承载 C++ 启动入口、QML 界面与资源。拆分主窗口、视频网格、视频卡片、工具栏和主题组件。
- 本次不创建 engine 实现或业务接口；后续由 UI 调用独立的 `webrtc_engine`。
- 窗口默认 `1440×900`，最小 `960×640`，使用系统标题栏。
- 视频区域随窗口缩放，固定三行三列、九个等大卡片；卡片显示“视频通道 01–09”“暂无视频”和“未连接”，预留保持 16:9 比例的视频内容区域。
- 使用深灰背景、圆角卡片和蓝色强调；图标随应用打包，不依赖在线资源或平台字体。
- 本次不制作设置表单、模拟视频、布局切换或安装包。
